# Figures shipped with the report

Five PNGs live in `report/figs/`, all generated by `figs/make_figs.py`. Four of them are embedded in
both `report/report.md` (Chinese) and `report/report-en.md` (English); `assembly_ladder.png` is the
chart form of the §5.5 assembly table and is kept in the bundle but left out of both reports to
respect the ≤ 10-page limit.

| file | what it shows | referenced from | generated by |
|---|---|---|---|
| `figs/position_nll.png` | Per-position mean NLL over the 256-token windows, baseline E0 vs the trained student (1,472 windows), with the first-16-position region marked | Figure 1 (图 1) — report.md and report-en.md §3.1 | `make_figs.py` → `fig_position_nll()`; reads the per-window NLL arrays and CSVs under `runs/phase3/diagnostics/` |
| `figs/val_curves_phase5.png` | Validation BPB (raw weights) of the 7,200-step recipes — baseline recipe, student without distillation, student with two-teacher distillation — two seeds each | Figure 2 (图 2) — report.md and report-en.md §5.2 | `make_figs.py` → `fig_val_curves_phase5()`; reads `runs/phase5/validation_curves.csv` and `runs/phase3/` teacher curves |
| `figs/distill_ablation.png` | Paired distillation effect (distilled arm vs no-distillation control) at 7,200 steps, both seeds, raw and EMA-selected | Figure 3 (图 3) — report.md and report-en.md §5.3 | `make_figs.py` → `fig_distill_ablation()`; reads `runs/phase5/` metrics |
| `figs/noise_floor.png` | (a) 1,200-step repeats of one recipe (n=4, +2 pooled) and (b) 7,200-step repeats (n=4, both dropout arms), with sd bands | Figure 4 (图 4) — report.md and report-en.md §6.1 | `make_figs.py` → `fig_noise_floor()`; reads `runs/phase3/results.csv`, `runs/phase4/results.csv` and the phase-4 raw arms' `metrics.json` |
| `figs/assembly_ladder.png` | The full single-knob assembly ladder of the frozen recipe (ten steps; the report's §5.5 table keeps five of them), paired difference per step, EMA-selected CPU fp32 | not embedded in report.md or report-en.md (chart form of the §5.5 table) | `make_figs.py` → `fig_assembly_ladder()`; reads the `metrics.json` of each rung's two seeds |

Regenerating (read-only over the run tree, writes only into this directory):

```bash
cd report/figs
python3 make_figs.py                 # all five figures
python3 make_figs.py --only position_nll,noise_floor
```

`make_figs.py` locates the run tree at `../../../MP1_student_starter/code` by default (i.e. the
directory holding `runs/`); pass it as the first argument or set `MP1_CODE_ROOT`. It needs only
`matplotlib` and `numpy`, and prints a per-figure note with the written size and any warnings.
Each figure's plotted values come from the same `metrics.json` / `validation_curves.csv` files that
`report/evidence.csv` summarises, so a number can be checked in either place.
